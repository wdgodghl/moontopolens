# 选题功能落实情况

MoonTopoLens 0.18.1 的主线是把小规模数据的多尺度连接分量、环路与空腔转成可复现的分析结果，并支持批量比较、解释和离线查看。

| 功能主线 | 当前实现 | 可复现入口 |
| --- | --- | --- |
| 点云和距离数据 | 欧氏距离、严格矩阵校验、Rips 二维骨架；可选 H2 所需三维骨架 | `square.json`、`octahedron-h2.json` |
| 时间序列 | 延迟嵌入、最多 12 组维数/滞后参数扫描、有限 H1 候选排序；自相关与分箱互信息提供探索性滞后参考值 | `periodic-series.json`、`periodic-sweep.json`、`periodic-lag-hints.json` |
| 多帧序列 | 2–12 个有序点云；逐帧 H0/H1 摘要、相邻瓶颈距离、H1 区间轨迹、时间线与变化图 | `evolving-loop.json` |
| 网格和灰度图 | lower-star 方格复形、P2/P5 PGM、8 位非交错 PNG、Otsu 与亮暗反转 | `ring-grid.json`、`ring-image.png` |
| 三维体素 | 2–32 层/行/列的 JSON 顶点网格或有界 NIfTI-1 单文件；分析 H0/H1/H2，导出简化 H2 代表面、可旋转投影、联动 Z 层和 NIfTI 世界坐标 | `hollow-volume.json`、`solid-volume.json` |
| 多帧体数据 | 2–8 帧同尺寸 JSON 或 NIfTI-1 4D 数据；逐帧 H0/H1/H2、相邻距离、H2 区间轨迹和离线报告 | `volume-evolution.json`、`volume-sequence *.nii.gz` |
| 稠密体数据近似分析 | `volume-coarse` 自动选最小预算内采样步长，以局部均值粗网格分析 H0/H1/H2；输出近似标记 | `volume-coarse` |
| 批量项目 | 最多 8 案例、12 个具名比较，全对 H0/H1 与可选 H2 距离矩阵、离线热图及单链接层次分组 | `batch-study.json`、`batch-h2-study.json`、`batch-volume-study.json` |
| 稳定性试验 | 点云坐标扰动，以及网格/PGM/PNG/体数据强度扰动；分别报告持久图距离 | `stability examples/square.json 0.02`、`field-stability examples/hollow-volume.json 0.05` |
| 同调与解释 | GF(2) 稀疏约化、H0/H1 与可选 H2 区间、代表链、精确 Betti 事件和尺度快照 | `analyze`、`slice` |
| 特征和比较 | 有限持续熵、持久景观、精确瓶颈距离、匹配见证、观察尺度推荐 | `landscape`、`compare`、`recommend` |
| 可分享结果 | JSON/CSV、条形码/持续图/树图 SVG、分析/比较/扫描/稳定性离线 HTML | 各命令的 `--out` 目录 |
| 性能与验证 | 邻接枚举稀疏单纯形、硬资源预算、稠密/稀疏基准、GUDHI 外部区间对照 | `benchmark.mjs`、`reference_gudhi.py`、CI |

## 实际边界

- H2 用于显式请求的点云、距离矩阵、延迟嵌入，以及默认分析 H2 的三维体素；双侧都分析 H2 时才计算其详细比较。批量 H2 矩阵对未分析维度和无有限匹配均使用空值，并提供逐案例分析标志以区分。二维网格和 PGM/PNG 图像仍仅分析 H0/H1。
- 体数据宽、高、深均为 2–32；精确分析的稠密高尺度输入可能先触及默认 4000、最高 10000 细胞预算。`volume-coarse` 明确是近似，步长大于 1 时结果不保证与原分辨率同调相同。NIfTI 导入限 1 MB 的单文件 `.nii`/`.nii.gz`，仅支持 uint8/int16/int32/float32、至多 8 帧的 NIfTI-1；不支持 NIfTI-2 或多文件。sform/qform/pixdim 坐标另行导出，不重新定向体数据。切片页显示采样顶点和 H2 代表面投影，不提供医学级体渲染或唯一空腔分割。
- PNG 支持单幅、8 位、非交错灰度/灰度透明/RGB/RGBA。调色板、16 位、交错 PNG 和 JPEG 尚不支持。图片最大 64×64，输入最大 1 MB；透明像素以白底合成。PNG 字节解码是 Node 适配层，拓扑分析由 MoonBit 核心完成。
- 时间序列候选排序只比较提交的组合；滞后参考值受配对样本量、分箱方式影响。两者都不推断周期或证明最佳参数；各组合可能有不同点数。
- 多帧轨迹基于相邻帧持久图区间的一种最优匹配，不证明物理对象身份；每帧最多 64 点，输入为同维点云且共用截止尺度。
- 稳定性分析使用固定的有界扰动和一次最优区间匹配；强度扰动对网格、图像及体数据比较 H0/H1/可选 H2，不提供概率、置信区间或真实特征证明。
- 分组使用单链接与最大合并间隙启发式；条件不一致或没有有限瓶颈距离的案例保持分离，不生成统计显著性结论。
- `max_cells` 默认 4000、上限 10000，点云或矩阵最多 128 点/行。邻接枚举降低稀疏输入的构建工作，但不是无限规模或流式计算保证；基准记录的是分析后 RSS，不是峰值内存。
- 高维点云图像只投影前两个坐标；不绘制 Rips 三角形和四面体的投影填充。代表链贪心缩短，不保证全局最短。
- 当前 Mooncakes 发布版本与仓库版本应查看模块页和 `moon.mod`；最终比赛验收由组织方决定。
