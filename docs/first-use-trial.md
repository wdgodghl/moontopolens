# 首次使用试用任务与记录表

目的：发现首次使用的阻塞与误解。当前只完成工程自动化复现，不以它替代独立用户试用；本文件是待使用的任务材料，没有声称已获得实际试用结果。

条件：试用者未阅读源码，从 README 开始，在允许的正常开发环境中操作。记录系统、工具链和项目版本，使用示例数据即可；测试过程中不由维护者代操作。需要提示时记录提示内容和所在步骤。

任务 A：找出支持自己的数值 CSV 的入口，预览选列，生成报告，说明输入单位、截止和一个区间的含义，找到它对应的原始数据，并用导出的请求重算。

任务 B：运行固定时间戳信号示例，找到一个监测窗口及其来源记录，说明变化提示和确认异常的区别，说明无真值时为什么没有准确率。查看一种简单方法对照，不能仅凭拓扑图作结论。

任务 C：故意选一个已经存在的输出目录，读错误后恢复运行；再说明报告中“未计算”“没有特征”“截止仍存活”“不可比较”之间的区别。

每个任务记录：是否独立完成、耗时、失败步骤、看到的原始报错、是否需要提示、输出是否可核验。时间只作观察，不预设或虚构结果。另记录对文档入口、参数和结果语义的误解，逐项关联到修复与回测。
