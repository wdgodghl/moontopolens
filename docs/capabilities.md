# 能力边界与运行条件

此表由 contracts/capabilities.json 生成，CLI 帮助和核心上限常量使用同一份定义。

| 入口 | 接受范围 | 结果边界 |
| --- | --- | --- |
| points | 0–128 点，1–32 维；默认 4000、最高 10000 细胞 | 保留全部点，欧氏 Rips；预算超限即失败 |
| points_sparse | 最多 8192 点、1–32 维；库 rips_sparse 默认 10000 细胞，JSON/CLI 默认 4000，均最多 10000 | 精确稀疏枚举，保留全部点；仍受坐标、团枚举与约化预算约束 |
| points-sample | 1–10000 个原点，选 1–128 点；4000 万坐标更新预算 | 显式近似；覆盖半径不是持久图误差保证 |
| matrix | 最多 128 行，方阵、对称、非负、对角为零 | 不强求三角不等式；数据语义与单位由输入者保证 |
| grid / image | 网格每轴 1–64，可用空网格；PNG/PGM 图像最多 64×64 | 顶点 lower-star，计算 H0/H1；PNG 有编码限制 |
| volume | 每轴 2–32，细胞默认 4000、最高 10000 | 顶点 lower-star，计算 H0/H1/H2；H2 代表链不是唯一孔洞标签 |
| pores | JSON 每轴 1–64；最多 1024 区域、8 个净空半径 | 体素中心阈值分割、六面邻接，体积/面积依赖物理标定 |
| NIfTI | 文件及解压后不超过 1000000 字节；每轴 2–32，最多 8 帧 | 有界 NIfTI-1；pores-nifti 仅单帧、正向轴对齐仿射 |
| signal_study | 8–8192 样本；窗口 8–128，最多 64 窗口，累计 64000 细胞 | 基准时段训练；变化提示不等于确认异常或诊断 |
| cohort / reliability | 组间独立设计总数 ≤14、配对 ≤8 对；重采样 ≤96 次 | 按研究条件解释；重复率与经验包络不是正式置信度 |

CLI 文件限制按 UTF-8 文件字节计；库 JSON/CSV 字符串限制按字符计，两者不等同。点数上限不保证细胞预算、匹配预算或运行内存一定够用。达到预算时明确失败，不自动降低精度。

## 可检查与需声明的条件

程序检查格式、尺寸、数值、已计算维度和部分观察条件。单位、独立采样、组间交换性、实验采样方案、材料配准与真实标签的可信性不能从格式验证中证明。普通 compare 允许数学图比较；种类或截止不同时会标明，不能据此认定具有领域可比性。

## 四种结果状态

- observed：已计算，并区分截止前死亡与截止时仍存活。
- not_computed：未计算该维度或代表链，不代表没有特征。
- empty：在声明条件下没有相应结果，不代表所有参数下都不存在。
- unavailable：距离或指标不可得，应查看相邻原因；不以 0 代替。

## 研究工作流

重采样重复率与经验分位数不代表真实概率或正式覆盖率。均值景观带只在明确 IID 独立采样假设和共同观察条件下覆盖固定 31 点网格；不覆盖单个区间或连续曲线。分组检验的 max-statistic 校正在联合可交换的完整零假设下解释。信号分数只表示相对基准变化；材料中心采样内切球不是连续全局最大球，净空连通不是渗透率。详情见 [研究条件](research-workflows.md)。
