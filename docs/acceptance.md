## 本地验证

- 类型检查和构建：JS、Wasm GC。
- 测试：两后端各 32 个测试；参考测试内部覆盖 12×11 个形状/尺度组合。
- CLI：七种示例、六种导出文件、快捷摘要、同图/异图比较、帮助、错误和输出冲突路径。
- HTML：通过 DOM 替身验证尺度滑块、筛选和代表边高亮；未验证真实浏览器布局。
- 已知环路：正方形 H1 `[1,√2)`；网格中心填充 H1 `[0,1)`。
- 已生成的包不代表已上传 Mooncakes。

源码量由 `node scripts/check-source.mjs` 复算。
统计排除测试和 host.mbt FFI，并另报告去除纯括号行后的代码行数。
当前非空非注释行 1297；再排除纯括号行后为 993 行（也排除 HTML/JS 多行模板）。
该统计口径用于内部质量检查，组织方“有效源码”口径由评审决定。

清理旧覆盖数据后，单元覆盖率工具记录 554/663 个计数点（约 83.6%），包含未被单元测试驱动的 CLI；
CLI 另有端到端场景验证。覆盖率不等于全部行为正确，尚无外部差分验证。
