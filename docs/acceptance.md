## 本地验证

- 类型检查和构建：JS、Wasm GC。
- 测试：两后端各 75 个测试；参考测试内部覆盖 12×11 个形状/尺度组合，匹配见证覆盖 12 对形状。
- CLI：八种基础示例、九种分析导出文件、快捷摘要、尺度推荐、同图/异图比较、帮助、错误和输出冲突路径。
- 新功能：每个示例在全部事件尺度核对快照 H0/H1 与分组数；景观 JSON/CSV/向量一致，双洞帐篷高度已核对。
- 比较：三组报告导出、原始索引与代价 CSV 一致、同图零距离与存活类数量不同路径。
- 切片：分组着色 SVG、存活代表链高亮、无坐标仅 JSON；无效选择不创建输出目录。
- HTML：通过 DOM 替身验证分析页滑块/筛选/高亮/翻页、比较页维度/对角线筛选；未验证真实浏览器布局。
- 已知环路：正方形 H1 `[1,√2)`；网格中心填充 H1 `[0,1)`；短暂环路 `[0.004,0.005)` 不在均匀采样中出现，但保留在精确事件和 HTML 曲线。
- PGM：P2 示例与等价 JSON 网格的区间一致；P5 8/16 位、非法灰度、截断、输出冲突路径已验证。
- 图像预处理：Otsu 阈值、常量图、亮色前景反转、单图与批量参数元数据已核对。
- 批量：六个案例、三个配对的完整输出与总索引核对；清单中的 `../` 路径被拒绝且未创建输出目录。
- 全对矩阵：六案例 H0/H1 对称、主对角零、CSV 行数、与单独比较距离一致、离线热图与条件提醒已核对；关闭开关时不生成矩阵文件。
- 尺度推荐：有限/截断 H1、无环路分簇和空特征路径均已核对；CLI 与分析、图像、批量导出的 JSON/CSV 一致，并在推荐尺度验证 H0/H1 和区间存活。
- 参数扫描：四组维数/滞后组合、统一景观采样网格、JSON/两份 CSV 的顺序与数值一致；重复或超量参数、信号长度不足会报错。
- 扩展功能：四案例层次分组与建议切分、点云八次固定扰动、参数候选排序、PNG 单图及批量输入、H2 八面体 `[1,2)` 均通过 CLI 场景。
- 网格填充与分页：尺度 0 的环形网格不绘制方格面，尺度 1 绘制四个；Rips 点云不绘制投影三角形。离线报告模拟超过 120 条区间，核对每页 50 条、翻页和筛选后页码重置。
- GUDHI 外部差分：既有 22 个 Rips 案例的 H0/H1 区间一致；新增八面体 H2 样例在本版 GitHub CI 中核对通过，方法和局限见 reference-validation.md。
- 性能基准：8–28 点稠密输入和 32–128 点稀疏输入，三次独立运行取中位数；记录核心耗时和分析后进程 RSS，见 performance.md。
- 时间序列滞后提示：交替序列和无效输入用例通过；CLI 示例产生六行扫描结果和两个参考值。
- Mooncakes 注册表 `wdgodghl/moontopolens` 返回最新 0.13.0、MIT、`build_status=success`；独立项目安装 `wdgodghl/moontopolens@0.13.0` 并调用新增 API 成功。
